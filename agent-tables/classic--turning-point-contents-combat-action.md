# Combat Action
- **Ruleset:** classic
- **Collection:** Turning Point Oracles
- **Table ID:** `classic/turning_point/contents/combat_action`
- **Source data:** `src/data/classic-turning_point.yaml`
## Description

Use this oracle to help inspire an action for an NPC in combat. When you’re not sure what your foe does next, particularly when they have initiative, roll on this table and interpret the result as appropriate to the situation.
## Results
### 1-3

Compel a surrender.


### 4-6

### 7-9

### 10-13

Seize something or someone.


### 14-17

### 18-21

### 22-25

### 26-29

### 30-33

### 34-39

### 40-45

### 46-52

### 53-60

### 90-99

### 100-100
