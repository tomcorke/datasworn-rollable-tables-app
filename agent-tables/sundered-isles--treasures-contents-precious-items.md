# Precious Items
- **Ruleset:** sundered_isles
- **Collection:** Treasures
- **Table ID:** `sundered_isles/treasures/contents/precious_items`
- **Source data:** `src/data/sundered_isles-treasures.yaml`
## Description

Roll or select a number of items on this table as set by the treasure’s Value (page 185). Each result represents a quantity of that item, such as a lockbox filled with pearls, a barrel of aged rum, or a stack of precious metal ingots. To instead reveal a specific item of intrinsic or personal worth, check the Tokens table (below).
